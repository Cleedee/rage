## 📖 Guia de Jogo

### Turno 1 — Preparação
1. **Redraw**: Mantenha mão com Caern + Step Sideways + combat action baixa.
2. **Recurso**: Jogue **Caern de Rytthiku** ou **Trinity Hive Caern** no pack.
3. **Umbra**: Nada ainda.
4. **Moot**: Vote conforme estratégia.
5. **Combate**: Se tiver **Umbral Escape** ou **Step Sideways**, ative e entre na Umbra. Caso contrário, use **Dodge/Evasion** para sobreviver.

### Turno 2 — Ativação da Umbra
1. **Recurso**: Jogue segundo Caern se tiver. Jogue **Beast-of-War** ou **Silver Claws** em Fade-To-Black.
2. **Umbra**: Use **Step Sideways** (3 copies) para mover Fade-To-Black para a Umbra.
3. **Combate**: 
   - **Fade-To-Black** na Umbra usa **Redirected Attack** (Gnosis 6+2=8) — reflete qualquer ação.
   - Se não tiver Redirected, use **Umbral Flurry** (dano = Gnosis).
   - Tim Rowantree (com Caern, Rage 3 Health 4) luta no physical.

### Turno 3 — Domínio Umbral
- **Spiritual Revelation**: Compre 2-4 cartas (1 por Caern em jogo).
- **Walking between Worlds**: Dê livre trânsito para outro personagem.
- **Airt Mastery**: Prenda inimigos na Umbra com **Close Gauntlet** + **Stuck Sideways**.
- **Umbral Wave**: Se muitos inimigos estão na Umbra, ative para dano em massa.
- **Gaia's Breath**: Cure dano nos seus personagens na Umbra.

### Turno 4+ — Finalização
- **Fade-To-Black** continua usando **Redirected Attack** e **Sap Spirit**.
- **Sees-through-Stars** usa Gauntlet de qualquer Caern para step sideways.
- **Shadow-Weaver** mantém Ananasi (se houver) com Gauntlet 1.
- Se a Umbra estiver dominada, ataque o **Hunting Grounds** para VP extra (Caern of Rytthiku permite).

## ⚡ Combos

### Combo Básico: Step + Redirect
```
Step Sideways → Fade-To-Black entra na Umbra
→ Redirected Attack (Gnosis 8) reflete ação do oponente
→ Oponente com Gnosis < 8 se auto-elimina
```

### Combo Controle: Caern + Close Gauntlet
```
Lake Nasser Wallow → Rites/Gifts cruzam Gauntlet
→ Close Gauntlet → todos na Umbra presos
→ Umbral Wave → dano em quem está preso
```

### Combo Suporte: Spiritual Revelation
```
3 Caerns em jogo
→ Spiritual Revelation → compra 3 cartas
→ Mais opções de Umbra
```

### Combo Defensivo: Walking between Worlds
```
Walking between Worlds em Tim Rowantree
→ Tim pode entrar/sair da Umbra livremente
→ Se ferido, foge para Umbra e se cura com Gaia's Breath
```

## 🔑 Prioridade de Mulligan

1. **Step Sideways** (809) — essencial para ativar Umbra
2. **Caern of Rytthiku** (579) — melhor Caern
3. **Fade-To-Black** (62) — personagem mais forte
4. **Low Blow** ou **Lucky Blow** — combat action barata
5. **Beast-of-War** (818) — buff de dano

Evite: Vital Blow (R6, muito caro cedo), Umbral Wave (situacional), Airt Mastery (só útil depois da Umbra ativa)
