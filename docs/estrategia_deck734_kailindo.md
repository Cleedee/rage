## ⚔️ Guia de Combate

### Abertura (Round 1)
```
CONTRA ATAQUE FÍSICO:   Dodge / Evasion / Block and Roll
CONTRA GIFTS/MAGIA:     Umbral Escape (sai do combate)
CONTRA MÚLTIPLOS:       Sudden Impediment (bloqueia tudo)
CONTRA ALVO FRACO:      Blood Atami (dmg4) ou Sap Spirit (dmg3 Unblockable)
```

### Meio do Combate
```
COM VANTAGEM:     Head Butt dmg4 / Overextended Attack dmg4
EM DESVANTAGEM:   Friends in High Places (encerra!)
PRECISA MATAR:    Clawstorm + 3 ataques
VS ARMADURA:      Sap Spirit (Unblockable)
```

### Fuga
```
Messenger's Fortitude → foge antes do combate começar
Umbral Escape → Fast Striking, sai na Umbra
Run Like Hell → foge do combate
```
